android-use 0.1.0 introduces agent control of Android phones through authorized ADB: accessible screen reads, Unicode input, snapshot-bound taps, gestures, app launch, screenshots, semantic waits, and batches.

Includes a stdio MCP server, CLI, background connection lifecycle, and independent GitHub Release installers for macOS, Linux x64 and Windows x64. Integrates with the use-family skills and marketplace. Unknown outcomes are never automatically replayed.

Hardware coverage and measurement conditions are documented in the repository. Native accessible fields and WebView editable fields are supported; custom-rendered input and protected surfaces may be unavailable. This release provides basic control; it does not include streaming or persistent on-phone services.
